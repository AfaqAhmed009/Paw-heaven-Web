
# 🐾 Paw Heaven

Paw Heaven is a full-stack **Pet Adoption and Marketplace** web application developed to connect pet lovers, adopters, and sellers on a single platform. The system allows users to browse pets, post pets for adoption or sale, search using filters, and manage listings through an intuitive interface. It also includes secure user authentication, pet management, and an admin panel to oversee platform activities, providing a seamless and user-friendly experience for pet owners and adopters.

---

# ⚙️ The Development Process

The project began with designing the database schema and user interface. The frontend was built using HTML, CSS, Bootstrap, and JavaScript, while PHP handled the backend logic and MySQL stored user and pet information. CRUD operations were implemented for managing users and pet listings, followed by testing and interface improvements to provide a smooth user experience.

# ▶️ Running the Project

1. Clone the repository.
2. Move the project folder to the **XAMPP `htdocs`** directory.
3. Start **Apache** and **MySQL** using the XAMPP Control Panel.
4. Import the provided MySQL database into **phpMyAdmin**.
5. Open your browser and navigate to:

   ```
   http://localhost/Paw-Heaven/
   ```
6. Register a new account or log in to explore the platform.
